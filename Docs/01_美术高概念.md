## 0. 已确立的三个方向

以下三项已作为既定美术方向确立，本文档其余部分全部以此为前提。

| 编号 | 问题 | 已确立方向 | 影响 |
|---|---|---|---|
| **A1** | Moodboard 有 5 个场景，策划案 §9.1 只有 3 章 | **第一章 = 黄泉线（地铁），第二章 = 百鬼市（商场），终章 = 阴司（医院）**；无尽楼（写字楼）、百鬼宅（小区）降级为**房间级皮肤**（事件房 / 精英房 / 宝藏房复用），不做独立章 | 直接决定 tile 集数量（3 套 vs 5 套），约 40% 场景资产量 |
| **A2** | 视角 | **约 55° 斜俯视**（云顶之弈式棋盘视角；策划案 §14.3 的 `y_sort_enabled` 与此一致） | 决定角色是否需要多朝向图，以及单位立绘的透视 |
| **A3** | 单位表现形式 | **2D 手绘 Sprite + 少量骨骼动画**（非 3D、非像素） | 决定管线、外包对象、动画成本 |

> A2 的推论很重要：`y_sort` + 俯视 3/4 意味着**单位是"站在格子上的立绘"**，不是"贴在格子上的图案"。所以单位需要**脚底接地阴影**来锚定所在格，否则 3/4 视角下玩家会判断错单位到底站在哪一格。这条列入 §9 硬性要求。

## 1. 一句话美术定位与三大美术支柱

### 1.1 一句话定位

> **「画面里 90% 是你今天真的见过的城市，10% 不对劲。恐怖来自那 10%，不来自那 90%。」**

对应 moodboard 主视觉那句世界观："在熟悉的城市中，我们走进了不熟悉的世界。"
美术的任务不是画一个鬼世界，而是**画一个可信的现代城市，然后精确地污染它**。

### 1.2 三大美术支柱

| 支柱 | 含义 | 判据（做完了怎么验收） |
|---|---|---|
| **V1 日常的可信度** | 城市部分必须写实、有生活垢、有年代感。城市不可信 → 异常不恐怖 | 任何一张场景图，**遮住异常元素后，应该像一张普通的城市夜景照片** |
| **V2 异常的克制** | 每个画面的"不对劲"控制在 1–3 处，且必须是**逻辑错误**而非血浆。玩家要先觉得"哪里怪"，再反应过来"哪里怪" | 每张场景图能明确列出**异常清单**，条目数 ≤3。数不出来、或数出 8 条 = 不合格 |
| **V3 战斗的可读性** | 战斗中氛围让位于信息。玩家必须 0.5 秒内读出：谁在哪、占几格、朝哪、下回合要干什么 | 把画面降到 25% 缩略图，仍能分清己方 / 敌方 / 危害格 / 体型轮廓 |

> **三条支柱的优先级是硬的：V3 > V1 > V2。**
> 当氛围与可读性冲突时（一定会冲突，见 §10.1 的红色冲突），**永远牺牲氛围**。这是 45 分钟一局、要玩几百小时的肉鸽，不是一次性的恐怖体验。

## 2. 核心转译公式：怪谈是怎么长在城市里的

这是本文档**最需要被外包和 AI 生成理解的一节**。所有场景与怪物设计都走同一个公式：

```
怪谈元素 = 【传统母题】 × 【现代城市载体】 × 【一处日常逻辑错误】
```

三项缺一不可：

- 缺【传统母题】→ 变成普通的都市废墟 / 克苏鲁，失去"东方"。
- 缺【现代城市载体】→ 变成古风灵异，失去"现代"，也失去玩家的代入。
- 缺【日常逻辑错误】→ 变成美术堆料，玩家只觉得"红红的挺好看"，不觉得怪。

### 2.1 转译词表（核心资产，持续扩充）

| 传统母题 | 现代城市载体 | 日常逻辑错误（异常点） | 用在 |
|---|---|---|---|
| 引路灯笼 | 地铁应急指示灯 / 出口绿灯 | 箭头全部指向同一个方向，且不是出口 | 黄泉线 |
| 纸钱 | 地铁票 / 购物小票 / 收据 | 票面日期是农历，或印着乘客自己的名字 | 黄泉线、百鬼市 |
| 过奈何桥 | 站台屏蔽门 / 地面黄色安全线 | 黄线变朱红，线内侧地砖是旧式青砖 | 黄泉线 |
| 走无常（勾魂使者） | 末班车司机 / 地铁安检员 | 制服正确、工牌正确，但**没有影子** | 黄泉线 |
| 门神 / 镇宅 | 商场安检闸机 / 门禁 | 闸机上贴黄符，刷卡机显示"已收" | 百鬼市 |
| 纸扎（纸马纸屋） | 商场家电区 / 儿童游乐区 | 冰箱电视是纸糊的，纸马停在扭蛋机旁 | 百鬼市 |
| 冥婚 | 商场婚纱店 | 婚纱是寿衣剪裁，模特两两成对面朝内 | 百鬼市 |
| 供品 / 上供 | 美食广场 / 便利店热食柜 | 每份餐盘插一支香，香灰积在餐桌上 | 百鬼市 |
| 冥币面额 | 价签 / 促销吊旗 | 单位不是元，是"年"（用寿命付账） | 百鬼市 |
| 头七 / 停灵 | 医院太平间 / 病床 | 床位牌上入院日期与"回家日期"是同一天 | 阴司 |
| 阴司文书 | 医院叫号屏 / 病历本 | 叫号屏在叫还没出生的号；病历是朱批字迹 | 阴司 |
| 孟婆汤 | 医院配药窗口 / 自动售水机 | 药袋上没有药名，只有一个"忘"字 | 阴司 |
| 无脸 / 面具 | 通勤人群 / 电梯乘客 | 所有人低头看手机，屏幕是灭的 | 通用 |
| 镜煞 | 电梯镜面 / 橱窗玻璃 | 反射里的人数比现场多一个 | 通用 |
| 鬼打墙 | 写字楼楼梯 / 商场扶梯 | 层数标识在重复；扶梯只上不下 | 无尽楼、百鬼市 |
| 招魂 | 手机推送 / 电子屏滚动字 | 消息来自没存过的号码，内容是自己昨天说的话 | 通用 |

**使用规则**：

1. 一个房间**最多用 3 条**。用满 6 条的房间不是恐怖，是杂货铺。
2. 同一条在同一章内**最多复用 2 次**，第三次必须换载体。
3. 每条都要能被"遮住即消失"—— 即异常是**可移除的图层**，方便腐蚀度分级（§11）复用同一张底图。

> **第 3 点是省钱的关键**：底图（城市）一张，异常图层按腐蚀度分 3 档叠加。同一个房间在腐蚀度 1 和腐蚀度 7 下看起来是两个地方，但美术只画了一张底图 + 三组贴花。

## 4. 色彩系统

### 4.1 全局色板（从 `总方向 Moodboard.png` 实测采样，非估值）

| 角色 | 名称 | HEX | 用途 | 占比目标 |
|---|---|---|---|---|
| 底 | 墨夜蓝 `INK` | `#0B0C17` | 场景最暗部、界面底 | 35–45% |
| 底 | 夜青 `NIGHT` | `#131A23` | 次暗部、面板 | 15–20% |
| 中 | 钢灰蓝 `STEEL` | `#2D3949` | 建筑、金属、混凝土 | 15% |
| 中 | 靛紫 `INDIGO` | `#3D2B45` | 阴影里的紫，异界感的来源 | 8% |
| 亮 | 幽紫 `LILAC` | `#6C4464` | 氛围光、雾、灵体 | 5% |
| 亮 | 香灰白 `ASH` | `#EEE7DD` | 纸、符、灯光、高光 | 4% |
| **强调** | **朱红 `VERMILION`** | **`#6D0409`** | **仅用于符号与危险** | **≤3%** |
| 强调 | 灯笼橙红 `LANTERN` | `#8A2B1C` | 灯笼、暖光源 | ≤3% |

> **朱红的 3% 上限是硬约束。** L0 moodboard 里红看起来很多，是因为它是一张**宣传图**（红在小图里抓眼）。实际游戏场景里红一旦超过 5%，两件事会同时发生：① 恐怖感变成廉价的血腥感；② **红色作为"伤害 / 危险"的 UI 功能色彻底失效**（见 §10.1）。
>
> 注意 `#6D0409` 的饱和度其实很高（96%），它之所以读起来"沉"，靠的是**低明度（43%）**。所以场景里的红要保持这个明度水位，不要试图靠"调灰"来压它 —— 见 §4.4。

### 4.2 分章色板

每章换色相，**不换明度结构**。明度结构（暗底 + 极少高光）全局统一，这是画面能一眼认出是同一个游戏的原因。

| 章 | 场景 | 色相偏向 | 实测主色（采样自 moodboard 缩略图） | 特征光源 | 一句话 |
|---|---|---|---|---|---|
| **第一章** | 地铁·黄泉线 | **靛蓝 → 紫** | `#0B0C17` `#292F4C` `#311726` `#5F4E73` `#B19CB8` | 冷白荧光管 + 单点朱红应急灯 | 又冷又空，只有你一个人 |
| **第二章** | 商场·百鬼市 | **暗红褐 → 暖橙** | `#181012` `#391A1A` `#563C42` `#836065` `#C3A8AA` | 大量灯笼暖光 + 冷蓝阴影 | 热闹得不正常 |
| **终章** | 医院·阴司 | **青灰 → 冷绿** | `#050D13` `#0B1E28` `#263B48` `#415D6F` `#88A4B4` | 全冷光、无暖色、无阴影 | 干净、明亮、没有一点人味 |

> **终章的反差设计**：前两章靠"暗"制造恐怖，终章靠"太亮太干净"。医院是唯一一个**照明充足、几乎没有暗部**的章节，且**完全禁用暖色**。这个反转能在不加资产量的前提下产生新的压迫感 —— 玩家在前 6 层学会了"暗处有东西"，第三章突然没有暗处，反而更慌。

### 4.3 储备场景色板

| 场景 | 色相偏向 | 实测主色 |
|---|---|---|
| 写字楼·无尽楼 | 蓝灰、单调、去饱和 | `#04090E` `#18222E` `#2D3949` `#495365` `#828DA2` |
| 小区·百鬼宅 | 深血褐、低明度 | `#0E0A0B` `#1B0C0E` `#351B1C` `#4B2A2B` `#895652` |

### 4.4 功能色（UI 专用，任何场景不得占用）

这一组色**在场景美术中被禁用**。它们是玩家的信息通道，不是氛围工具。

| 功能 | 名称 | HEX | 明度 V | 语义 |
|---|---|---|---|---|
| 伤害 / 危险 / 敌方 | `FN_DANGER` | `#FF3B30` | 100% | 亮红 |
| 可移动 / 己方 / 合法 | `FN_ALLY` | `#3DD6D0` | 84% | 青蓝 |
| 格挡 / 防御 | `FN_BLOCK` | `#7FA8D9` | 85% | 冷蓝 |
| 暴击 / 稀有 / 奖励 | `FN_GOLD` | `#FFC94D` | 100% | 金 |
| 符文 / 规则改写 | `FN_RUNE` | `#B47FE8` | 91% | 紫 |
| 治疗 | `FN_HEAL` | `#6ED89A` | 85% | 绿 |
| 腐蚀度 | `FN_CORRUPT` | `#C0392B` → `#FF1E1E` | 75% → 100% | 随腐蚀度升高提亮 |

> **`#FF3B30` 与 `#6D0409` 的区分是可读性的地基，而区分它们的是明度、不是饱和度。**
> 实测：场景朱红 `#6D0409` 色相 357°、饱和 96%、**明度仅 43%**；UI 危险红 `#FF3B30` 色相 3°、饱和 81%、**明度 100%**。两者色相几乎相同，饱和度也都很高 —— **唯一的分野是"暗 vs 亮"**。
> 所以给外包的指令必须是「**场景红要压暗（V ≤ 45%），UI 红要拉亮（V = 100%）**」，而不是「场景红要降饱和」。降饱和会得到一个发灰的脏红，既不好看也依然会与 UI 红混淆。**场景中一旦出现高明度亮红，这套区分立刻崩塌。**

**功能色之间的可分性**（实测色相间距）：多数两两间距 ≥90°，但有三对偏近，需追加约束：

| 组合 | 色相差 | 约束 |
|---|---|---|
| `FN_ALLY` vs `FN_HEAL` | 32.7° | 都偏青绿。**治疗只出现在数字与图标上，不用于地面填充**；地面填充的青绿一律是"可移动"，避免同屏歧义 |
| `FN_ALLY` vs `FN_BLOCK` | 35.0° | 都偏蓝。`FN_BLOCK` 只用于**护盾数值与盾图标**，不用于地面高亮 |
| `FN_DANGER` vs `FN_GOLD` | 38.6° | 红与金相邻。金**永不用于地面危害填充**，只用于奖励 / 暴击 / 稀有边框 |

> 归纳成一条可执行规则：**地面高亮层只允许用两种颜色 —— 青蓝（合法/己方）与亮红（危险/非法）。** 其余四个功能色仅存在于 UI 元素、图标与数字上。这样即使色相接近，也永远不会在同一个视觉平面里争夺解读。

## 5. 光照、材质、镜头

### 5.1 光照

| 规则 | 说明 |
|---|---|
| **光源必须有现实出处** | 荧光管、灯箱、手机屏、应急灯、灯笼、电梯轿厢灯、便利店冷柜。**禁止无源的"氛围紫光"** —— 那是廉价感的第一来源 |
| **逆光 / 背光为主** | L0 已锁定剪影语言。主体多数时候是暗的，靠背后光源勾边 |
| **一张画面一个主光** | 主光 + 最多 2 个辅光 / 点缀光。多光源互相打架 = 画面脏 |
| **湿地面反射** | 全局标配。这是把"少量光源"放大成"整张画面有氛围"的最省钱手段 |
| **雾 / 体积光** | 分章递进：第一章薄雾（隧道风），第二章香烟 / 香灰雾，终章无雾（干净是它的恐怖来源） |

### 5.2 材质关键词

| 类别 | 关键词 |
|---|---|
| **城市（V1 可信度）** | 瓷砖缝里的黑垢、不锈钢指纹、贴纸残胶、掉漆的黄漆、水渍、空调滴水痕、褪色的塑料灯箱、被撕过的小广告 |
| **传统（东方符号）** | 宣纸纤维、朱砂颗粒、香灰、木刻拓印、褪色红绸、纸扎的竹骨与糊纸、金箔 |
| **异常（污染点）** | 材质**错位** —— 现代物件用传统材质做（纸糊的冰箱），传统物件用现代材质做（不锈钢牌位、亚克力灵位牌） |

> **"材质错位"是本项目最独特的视觉手段，优先用它，不要用血。** 一个纸糊的电视机比一面血墙更符合本项目调性，也更省重绘成本。

### 5.3 镜头

| 用途 | 镜头 |
|---|---|
| 战斗 | 固定约 55° 斜俯视（A2），可缩放拖拽。**战斗中禁止镜头旋转** —— 六边形战场旋转后玩家会失去方位感 |
| 房间进入过场 | 1.5 秒短镜头，从"日常视角"推向战场俯视，异常点在这 1.5 秒里出现一次 |
| 事件 / 商店 | 平视单点透视，走廊 / 店铺纵深感 |
| Boss 进入 | 仰视 —— 全游戏唯一使用仰视的地方（承载 6 格体型的压迫感） |

### 5.4 战场舞台：三段式构图

战斗场景是一张完整原画，**棋盘画在场景世界里**，不是悬浮的游戏 UI。每章战斗原画按三段式舞台构图：

| 区域 | 占宽 | 职责 |
|---|---|---|
| 左侧 | ~20% | 叙事动态层：地铁进站出站 / 扶梯纸人 / 电梯楼层闪烁 |
| 中央 | ~60% | 战斗区：平整空地，六边形**画在地面上**（粉笔 / 油漆 / 警戒线质感） |
| 右侧 | ~20% | 氛围层：电梯 / 闸机 / 灯笼阵列 / 病床 / 配药窗口 |

- 格线由程序叠加，原画不画格线；中央必须留一块平整、干净、稍亮、无遮挡的空地
- 左右动态夹住中央静态，把视线自然推向棋盘
- 动态元素不越过棋盘边界；出牌 / 敌方回合等关键时刻，外围动态可短暂降级甚至静止（“列车突然停在隧道里”）

## 6. 章节场景高概念

### 6.1 第一章 · 地铁 · 黄泉线

> **「通往未知的末班车，永远到不了终点。」**（L0 原句）

**一句话美术目标**：拍一张真实的凌晨三点地铁站照片，然后只改三样东西。

**空间类型**（对应策划案 §9.7 的地形模板库）：

| 空间 | 战场特征 | 与体型系统的关系 |
|---|---|---|
| **站台** | 开阔，长条形，两侧屏蔽门 | 宽敞，6 格 Boss 的主战场 |
| **车厢内** | **狭长，单行道** | ⭐ 策划案 §4.2 点名要求的"狭道 / 门洞"模板 —— 巨人在此发挥"谁也过不去" |
| **隧道 / 检修通道** | 狭窄 + 分叉，有柱子遮挡 | 视线阻断，弓箭手风筝路线 |

**关键视觉元素清单**：

| 元素 | 日常形态 | 异常化 | 优先级 |
|---|---|---|---|
| 站名牌 | 灯箱站名 + 拼音 | 站名逐层变成生僻字 / 繁体，终章层站名**空白**；**拼音始终正常**（这个细节最恐怖） | **P0** |
| 线路图 | 彩色线路图 | 线是**闭环，没有终点站**；末端站点是朱红圆点，正在往下渗色 | **P0** |
| 地面安全线 | 黄色警戒线 | 变**朱红**，线内侧地砖是旧式青砖（两个年代的地面拼在一起） | **P0** |
| 应急指示灯 | 绿色出口箭头 | 所有箭头指同一方向，且指向隧道 | **P0** |
| 乘客 | 通勤剪影 | 无脸；**影子方向与光源不符**；低头看灭屏的手机 | **P0** |
| 隧道口 | 黑暗洞口 | 无穷深，有风幕但**站台的纸屑不动** | **P0** |
| 拉手环 | 一排吊环 | 无风自动摇晃，**摆动不同步**（各自按各自的节奏） | P1 |

| 车门 | 不锈钢门 | 贴着黄符，符纸盖在"当心夹手"贴纸上 | P1 |

### 6.2 第二章 · 商场 · 百鬼市

> **「凌晨三点营业的商场，售卖着非人的商品。」**（L0 原句）

**一句话美术目标**：第一章是"空得不对"，第二章是**"热闹得不对"**。灯全亮、音乐在放、店都开着，但客人不是人。

**这是全游戏视觉密度最高的一章**，也是与第一章形成对比的关键：第一章教玩家"暗处有东西"，第二章告诉玩家"亮处也有"。

**空间类型**：

| 空间 | 战场特征 | 与体型系统的关系 |
|---|---|---|
| **中庭** | 最开阔，圆形 / 方形天井，多层可见 | 6 格 Boss 主场；纵深感最强 |
| **店铺内** | 中等，货架分隔成迷宫 | 货架 = 视线阻断 + 可破坏 |
| **扶梯 / 天井边缘** | **狭长 + 边缘坠落危害** | ⭐ 推拉机制（策划案 §8.6）的舞台：把敌人推下天井 |
| **美食广场** | 中等，桌椅密集 | 大量小型障碍，大体型行动受限 |
| **后场通道 / 员工区** | 狭窄，无装饰，冷光 | 与前场的华丽形成反差 —— "后台没有伪装" |

**关键视觉元素清单**：

| 元素 | 日常形态 | 异常化 | 优先级 |
|---|---|---|---|
| 中庭吊饰 | 促销吊旗 + 节日装饰 | 红灯笼与促销吊旗**混挂**，灯笼一路挂到看不见的高处 | **P0** |
| 楼层索引牌 | 1F 化妆品 2F 女装… | 出现 `-1F 阴货`、`4F`、`13F`；楼层数不连续 | **P0** |
| 扶梯 | 上下双向 | **只上不下**；或两条都在上升 | **P0** |
| 店员 | 制服 + 胸牌 | **纸人**：身体是纸扎竹骨，穿着正确的制服，胸牌工号写在符纸上 | **P0** |
| 家电区 | 冰箱电视 | **纸糊的**冰箱电视，带正常的品牌 logo | **P0**（材质错位的代表作） |
| 价签 | ¥199 | 单位是"年"；促销写"买一送一，寿限自理" | **P0** |
| 天井 | 可以往下看几层 | 往下**无底**；往上灯笼无尽 | **P0** |
| 婚纱店 | 婚纱 + 模特 | 婚纱是**寿衣剪裁**；模特两两成对、全部面朝内 | P1 |
| 美食广场 | 餐盘 + 桌椅 | 每份餐插一支香；桌上积香灰；筷子直插饭中 | P1 |
| 儿童游乐区 | 摇摇车 + 扭蛋机 | 纸扎马停在扭蛋机旁；摇摇车无人自动摇 | P1 |
| 玻璃橱窗 | 反射中庭 | 模特在反射里转头 | P1 |
| 广播 | 商场促销广播 | 内容正常，音色是**戏曲腔**（音频侧，此处记录以便同步） | P1 |
| 香水柜 | 玻璃柜 + 试香纸 | 试香纸是黄符；柜里是香烛 | P2 |
| 安检闸机 | 门禁 | 贴黄符；刷卡显示"已收" | P2 |

**复用红利**：`货架`、`模特`、`桌椅`、`吊灯笼` 四类 prop 可组合出全部店铺 —— 店铺的区别靠贴图与 prop 组合产生。

### 6.3 终章 · 医院 · 阴司

> **「白天是医院，夜晚是阴间的入口。」**（L0 原句）

**一句话美术目标**：**唯一一个明亮、干净、没有暗部的章节。** 恐怖来自"过于正常"。

| 规则 | 说明 |
|---|---|
| 照明 | 全冷白荧光，均匀铺满，**几乎没有阴影** |
| 暖色 | **完全禁用**。没有灯笼、没有朱红灯；唯一的红是朱批与"急"字 |
| 材质 | 全新、无垢、反光。走廊地板刚打过蜡 |
| 异常 | 更少、更精准（每战场 **1–2 条**），且全部是**文字与数字的错误**：叫号屏、床位牌、病历、药袋 |

**关键视觉元素**：叫号屏（在叫还没出生的号）／床位牌（入院与"回家"同日）／药袋（无药名，只有"忘"字）／病历（朱批字迹）／太平间推床（停在走廊中央，被单下有形状）／候诊椅（坐满，全部低头，没有一个抬头）／消防疏散图（图上的楼层平面不是这一层）。

**资产量最省的一章**，因为干净 = 细节少。

### 6.4 储备场景（不进 v1 主线）

按 A1 决策，这两个降级为**房间级皮肤**，用于事件房 / 精英房 / 宝藏房，复用主线 tile + 少量专属 prop：

- **写字楼 · 无尽楼** ——「永远到不了顶层的楼梯，电梯通往另一个世界。」视觉核心是**重复与单调**：同一段楼梯、同一层办公区的复制感，楼层数字在重复。是"鬼打墙"母题的最佳载体，资产极省（一个格子间模块 + 一段楼梯，靠复制产生恐怖）。
- **小区 · 百鬼宅** ——「你以为这里是居民楼，但其实是妖怪的巢穴。」视觉核心是**私人领域的入侵感**：正常的楼道、正常的防盗门、门上贴着不同人家的春联，但每一扇门缝下都有红光。

> 若未来扩为"5 章"：**无尽楼可以最省钱地扩成一整章**（重复即资产复用），百鬼宅最贵（每户人家都要独特细节）。要加章，**优先加无尽楼**。

## 7. 角色视觉规则（四职业）

L0 已锁定四职业：**镇邪者 / 方士 / 御灵者 / 妖化者**。策划案 §4.2 的四英雄是 **骑士 / 法师 / 弓箭手 / 巨人**。

> ⚠️ **术语说明**：L0 的四职业是对外的世界观命名，策划案 §4.2 的四英雄是内部的机制原型，一一对应如下。

| L0 职业 | 策划案原型 | 体型 | 现代身份 | 传统力量 | 视觉配比 | 关键道具 |
|---|---|---|---|---|---|---|
| **镇邪者** | 骑士（1 格 · 坦克） | 1 格 | 异常事件处理员（公职感） | 以人之力，镇压妖邪 | 现代 70% / 传统 30% | 战术背心 + 防爆盾（盾面是符板）／臂章／朱红符条 |
| **方士** | 法师（1 格 · 组合技） | 1 格 | 民俗研究员（学者感） | 以术法，改写规则 | 现代 60% / 传统 40% | 白大褂 / 风衣 + 罗盘／线装书／符笔／眼镜 |
| **御灵者** | 弓箭手（1 格 · 风筝） | 1 格 | 灵异调查者（自媒体感） | 以怪谈，为己所用 | 现代 80% / 传统 20% | 手机 / 相机（当作法器）／耳机／自拍杆／铃 |
| **妖化者** | 巨人（3 格 · 地形） | **3 格** | 异常感染者 | 以自身，化为妖 | 现代 40% / 传统 60%（**非人部分 30%**） | 破损的现代衣物／已经不是人的肢体／朱红筋络 |

### 7.1 角色设计硬规则

1. **每个角色都必须一眼看出"是现代人"** —— 除妖化者外，现代服装占比不低于 60%。
2. **传统力量必须表现为"外挂"而非"自带"** —— 符纸是贴上去的、法器是拿在手里的、印记是画上去的。这个区分让"人 vs 妖"的边界可见，而**妖化者的设计意义就是这个边界正在消失**。
3. **妖化者是唯一 3 格体型的玩家角色**，视觉上必须让"占 3 格"合理：不是"一个很胖的人"，而是**身体已经在向外蔓延**（多出的肢体、拖曳的影子、地面上的朱红筋络）。参考 L0 moodboard 妖化者立绘的红色扩散处理。
4. **配色**：每职业一个专属主题色。主题色是识别色而非服装主色，详见 §7.2。
5. **战场表现**：1 格角色 sprite 高约 1.6 格，3 格角色约 2.2 格。

### 7.2 主题色系统

主题色是**识别色**，不是服装主色。角色服装的 70–80% 仍是黑 / 炭灰 / 米白等现代中性色，主题色只占全身 10–20%，出现在法器、内衬、纹样、袖口、腰封等**切割位**上 —— 既保住「现代都市」的底色，又让四个角色在暗场景里一眼可分。

#### 总规则

| 项 | 规则 |
|---|---|
| 主题色占比 | 10–20%，不超过 30% |
| 主题色位置 | 法器、内衬、纹路、袖口、腰封、发光点 |
| 服装主色 | 黑 / 炭灰 / 米白 / 冷灰，负责现代感与可读性 |
| 黑色切割 | 黑色禁止满铺 —— 外套敞开露出亮色内搭，肩线、衣摆边缘、金属件负责把黑色「切开」 |
| 轮廓光 | 每个角色有一条从头顶到脚底**连续不断**的冷色 rim light，色相随主题色微调 |
| 明度关系 | 角色整体亮于脚下地面约 1.5–2 档 —— 角色是信息，不参与场景的恐怖氛围 |
| 功能色避让 | 主题色不得占用 §4.4 功能色语义（亮红 = 危险、青蓝 = 合法、金 = 奖励、紫 = 符文） |

#### 四职业主题色

| 角色 | 主题色 | 提亮档 | 色相语义 | 主题色位置 | 一句话 |
|---|---|---|---|---|---|
| **镇邪者** | 朱砂红 `#6D0409` | `#A31E24` | 镇压 —— 以人镇妖 | 符条、盾面刻纹、臂章、腰间绳结 | 炭黑战术装上的暗朱砂 |
| **方士** | 青蓝 `#2A6B8A` | `#3E8FB0` | 知识 —— 术法与秩序 | 罗盘指针、眼镜反光、符笔墨线、袖口内衬 | 灰白研究服上的青蓝 |
| **御灵者** | 幽紫 `#6C4464` | `#8E5D8C` | 边缘 —— 与怪谈共生 | 手机屏幕光、铃铛、耳机线、衣侧反光条 | 深灰机能服上的雾紫 |
| **妖化者** | 高饱和红 `#C21023` | 发光处 `#FF3B4E` | 感染 —— 人正化为妖 | 朱红筋络、眼睛、裂纹、地面延伸的妖纹 | 破损现代衣物上的朱红筋络 |

> **妖化者是唯一允许使用高饱和红的角色** —— 「危险」就是他的设定本身，玩家操作他时应持续感到不安。但红色仍须控制在小面积（筋络、眼、裂纹），不做整块红。

#### 与功能色的冲突处理

- 镇邪者的朱砂红保持**低明度**（V ≤ 45%），与 UI 危险红 `FN_DANGER`（V = 100%）靠明度区分
- 方士的青蓝**偏灰偏深**，只作服装点缀，不与地面合法高亮 `FN_ALLY` 争抢
- 御灵者用**灰紫 / 雾紫**，与符文系统 `FN_RUNE` 的发光紫拉开明度差
- 妖化者的高饱和红只出现在**角色自身与贴地妖纹**上，永不进入 UI 或高亮层

## 8. 怪物视觉规则（含体型系统的视觉承载）

L0 已给出五个方向：`狐妖·百鬼`／`山魈·都市异形`／`地铁幽灵·末班车`／`纸人·商场店员`／`无脸乘客·电梯`。

### 8.1 怪物设计公式

同 §2 的转译公式，但对怪物追加一条：

```
怪物 = 【传统妖怪原型】 × 【现代城市职业/物件】 × 【一处人体逻辑错误】
```

第三项**必须是人体的错误**（关节反向、影子不对、面部缺失、比例错误、动作不同步），**不能是伤口**。

| 原型 | 现代载体 | 人体错误 | 章 | 体型 |
|---|---|---|---|---|
| 纸人 | 商场店员（制服 + 胸牌） | 关节是竹骨的，转身时**身体先转，头后转** | 二 | 1 格 |
| 无脸鬼 | 通勤乘客 / 电梯乘客 | 五官处是**平的皮肤**，但仍会"看"你 | 一 | 1 格 |
| 缢鬼 | 地铁拉手环 | 悬在半空，脚尖离地 3 厘米 | 一 | 1 格 |
| 狐妖 | 夜店 / 柜姐 / 网红 | 太完美（对称到不自然），影子是四足的 | 二 | 1 格 |
| 镜煞 | 电梯 / 橱窗 | 动作比本体**慢半拍** | 通用 | 1 格 |
| 百鬼群 | 商场客流 | 一群人，**步频完全同步** | 二 | 1 格 × 群 |
| 阴司吏 | 医院护士 / 医生 | 手上永远拿着病历，写的是你的名字 | 终 | 1 格 |
| 山魈 | 都市异形（工人 / 清洁工） | 四足化，关节反向，用手行走 | 一 / 二 | **3 格** |
| 走无常 | 末班车司机 / 安检员 | 制服完美，**没有影子** | 一 | 3 格（精英） |
| 纸扎马 | 商场儿童区 | 纸做的，但会呼吸（纸面起伏） | 二 | 3 格 |
| 车（本体） | 末班车列车 | —— | 一 Boss | **6 格** |
| 中庭（本体） | 商场建筑本身 | —— | 二 Boss | **6 格** |

> **两个 Boss 都是"建筑 / 载具本身"**，不是大型人形。理由：① 策划案 §8.2 规定 6 格体型只给精英与 Boss，而 6 格在 7×7 战场占 12%，人形放大到这个尺寸会很蠢；② "整座商场就是那个鬼"完全符合本项目"日常物件才是异常"的调性；③ 资产上，Boss 可以是**战场本身的一部分**，省一整套大型单位动画。

### 8.2 体型的视觉硬规则（策划案 §13.2 的美术承载）

体型系统若不可读，玩家会一直误判"我能不能走进去"。因此：

| 体型 | 占格 | 剪影规则 | Sprite 高度 | 必须做到 |
|---|---|---|---|---|
| **1 格** | 1 | **直立人形**，竖向剪影 | ≈1.6 格 | 与玩家角色同尺度，一眼是"人" |
| **3 格** | 3 | **非人比例**：四足 / 横向展开 / 拖行。**横向剪影必须明显宽于 1 格单位** | ≈2.2 格 | 剪影不能是"放大的人形"，否则玩家读不出它占 3 格 |
| **6 格** | 6 | **建筑 / 结构尺度**，剪影有超出屏幕感 | ≈3.5 格 | 要有明确的"结构"感（车厢、天井），不是"很大的怪" |

**三条不可省略的实现要求**（策划案 §13.2 原文要求）：

1. **footprint 完整描边**：所有单位按占格完整描边，不只画锚点格。用 `Line2D` 或 shader（策划案 §14.3）。
2. **接地阴影**：3/4 视角下，每个单位在**每一个占用格**上画一个接地阴影椭圆 —— 这是玩家判断"它到底站在哪"的唯一可靠线索。
3. **移动预览显示 footprint**：拖动时实时显示落点完整占位与合法性（合法 = `FN_ALLY` 青蓝，非法 = `FN_DANGER` 红）。

> **视觉密度与体型成反比。** 6 格 Boss 的贴图细节要比 1 格小怪**更简洁**。它已经用尺寸赢得了注意力，再堆细节只会让战场变糊，玩家分不清"Boss 的装饰"和"地面的危害格"。

### 8.3 意图预告的视觉规范（策划案 §8.7 / §13.2）

敌人意图是本游戏最关键的信息之一 —— 策划案明确要求玩家能读出"意图是否可躲"。

| 意图 | 图标 | 颜色 | 附加表现 |
|---|---|---|---|
| 攻击 | 剑 / 爪 + 数值 | `FN_DANGER` | 地面高亮**预定打击格** |
| 范围攻击 | 扩散环 + 数值 | `FN_DANGER` 半透明填充 | 完整波及范围铺色 |
| 移动 | 箭头 | `FN_GOLD` | 虚线路径 + 落点 footprint 虚影 |
| buff 自身 | 上箭头 | `FN_GOLD` | —— |
| debuff 玩家 | 下箭头 | `FN_RUNE` | —— |
| 蓄力（多回合） | 沙漏 + 层数 | `FN_DANGER` 描边闪烁 | 强化边框，必须与单回合攻击明显不同 |
| **可躲 vs 追踪** | 打击格**实线** = 打空地（可躲）／**虚线锁定 + 连线到玩家** = 追踪（躲不掉） | —— | ⭐ 策划案 §13.2 点名要求，**不可省略** |

> 「可躲 / 追踪」的区分最容易被美术漏掉，但它决定了玩家这一回合是"走位"还是"硬吃"。**实线 = 打位置，虚线 + 连线 = 打人**，这条约定必须全游戏统一。

## 9. 战场可读性视觉规则

战场按「地形 → 危害 → 高亮 → 单位」四层叠加：地形与危害是场景，高亮与单位是信息。以下规则全部服务这一分层。

### 9.1 战场可读性硬规则

直接服务 V3 支柱与策划案 §13.2，**每条都不可协商**。

| 编号 | 规则 | 理由 |
|---|---|---|
| **R1** | 地形 tile 的**明度对比不超过 20%**，花纹不超过 tile 面积 30% | 地面是背景，不是主角。地面太花 → 高亮层看不见 |
| **R2** | **功能色只出现在高亮层与 UI 上**，永不出现在地形与 prop 上 | §4.4 的功能色专用原则 |
| **R3** | 危害格必须**同时**用 ① 颜色 ② 图案 ③ 微动画 三重编码 | 色盲可访问性 + 缩略图下仍可辨 |
| **R4** | 单位与地面的明度差 ≥ 40% | 剪影可读，25% 缩略图下仍能分清 |
| **R5** | 每个单位在**每个占用格**上有接地阴影 | 3/4 视角下判断所在格的唯一可靠线索（§8.2） |
| **R6** | 己方 / 敌方用**轮廓光颜色**区分（己方 `FN_ALLY` 青蓝，敌方 `FN_DANGER` 红），不靠底座圆环 | 底座圆环会与 `HighlightLayer` 抢视觉；轮廓光在密集战场更清晰 |
| **R7** | 场景暗部不得暗到看不清 tile 边界 —— **格线始终可见**，最低 15% 不透明度 | 六边形战棋的格线是操作基础，氛围不能吃掉它 |
| **R8** | 所有战斗特效**时长 ≤0.4 秒**，且必须支持一键跳过 | 策划案 §13.2：肉鸽玩家会玩几百小时 |
| **R9** | 特效**不得遮挡目标格**：伤害数字向上飘，特效向外扩散，格心保持可见 | 连续结算时玩家要能持续读到战场状态 |

> **R7 与氛围的冲突是本项目最典型的取舍。** "暗到看不清"恰恰是恐怖游戏想要的效果，但这是战棋。解法不是妥协亮度，而是**把恐怖放到战斗之外**：过场镜头、地图界面、事件插画可以很暗；战斗中的战场必须清晰。这也是 §5.3 给"房间进入过场 1.5 秒"的原因 —— **那 1.5 秒是氛围的配额，战斗回合内不再给。**

## 10. UI 视觉语言：可读性优先级高于氛围

### 10.1 必须先解决的冲突：红色

**问题**：本项目的氛围色是朱红（灯笼、符纸、安全线），而战棋的危险色也是红（伤害、敌方、非法落点）。二者同屏必然干扰。

**解法（三条同时生效）**：

| 手段 | 具体做法 |
|---|---|
| **明度分离**（主要手段） | 场景红一律**压暗**（`#6D0409`，明度 ≤45%）；UI 红一律**拉亮**（`#FF3B30`，明度 100%）。**场景中禁止出现高明度亮红** —— 注意是压明度，不是降饱和（§4.4） |
| **面积分离** | 场景红 ≤3%（§4.1 硬约束）；UI 红只在需要时出现，用完即消失 |
| **运动分离** | 场景红**永不闪烁、永不动画**；UI 红**必带出现动画**（渐显 / 脉冲）。运动即信息，静止即氛围 |

> 这三条构成一句可以口头传达给任何外包的规则：**「压暗、不动的红是装饰；明亮、会动的红是威胁。」**

### 10.2 UI 材质语言

在**功能清晰**的前提下用材质承载世界观（策划案 §13.1 的布局不变，本节只定视觉）：

| 元素 | 材质语言 |
|---|---|
| 面板底 | 深色磨砂 + 极细符纹暗纹（对比度不超过 8%） |
| 面板边框 | 细金线 / 朱红细线，**1–2 px** |
| 卡牌边框 | **符纸质感**：宣纸纤维 + 朱砂边。稀有度靠边框材质递进（纸 → 描金纸 → 朱批纸 → 金箔） |
| 符文槽 | 六边形（呼应战场），空槽是刻痕，装填后从槽内发紫光 `FN_RUNE` |
| 体力 | 香 / 烛的形式（点着的支数 = 剩余体力），比抽象圆点更有调性且同样清晰 |
| 血条 | 直线条 + 数字。**不做花哨造型** —— 血条是最高频读取的信息 |
| 按钮 | 实体感 + 明确按下态。**禁止纯文字无边框按钮**（恐怖氛围下低对比按钮 = 不可发现） |
| 字体 | 正文用**高可读黑体**；标题 / 站名 / 招牌用宋体或楷体承载东方感。**数值区一律等宽字体** |

> **字体分工是最省力的"东方感"来源**：只要标题是宋体、数字是等宽黑体，整个 UI 立刻既有调性又能读。反过来，如果把数值也做成毛笔字，玩家每回合都要费力辨认伤害值。

## 11. 腐蚀度的视觉表达

腐蚀度（策划案 §9.4）是本项目唯一需要**美术随游戏状态动态变化**的系统，也是 §2.1「异常是可移除图层」这条纪律的兑现处。

| 腐蚀度 | 视觉档位 | 实现手段 | 玩家感受 |
|---|---|---|---|
| **0–2** | 干净 | 基础后处理 | "这就是个地铁站" |
| **3–5** | 渗透 | ① 色相往红偏 5–8° ② 雾密度 +30% ③ 启用**异常贴花组 A**（符纸、渗色、多出的影子） | "刚才是不是没这些东西？" |
| **6–8** | 侵蚀 | ① 红饱和度 +25% ② 暗角加强 ③ 贴花组 B（结构扭曲、灯笼、朱红筋络） ④ 画面**极轻微呼吸缩放**（±0.5%，周期 4s） | "这里已经不是地铁了" |
| **9+** | 沦陷 | ① 全局偏红 ② 灯光闪烁 ③ 贴花组 C ④ UI 边框渗出朱红 | "我该跑了" |

> **后处理不得影响 UI 与高亮层** —— 腐蚀度 9 时全局偏红，如果 UI 也偏红，`FN_DANGER` 就读不出来，会摧毁 §10.1 的红色分离。档位切换必须是**渐变**（≥1.5s）而非跳变：玩家应该"没注意到什么时候变的"。

> **这是本文档里性价比最高的设计。** 一套后处理参数让 9 层场景产生明显递进，同时让「贪婪打法」（策划案 §9.4：刷满全层再打 Boss）有了直接可见的代价 —— **玩家能"看见"自己有多贪。** 这比 UI 上的数字条有效得多。

## 12. 卡牌、符文、装备的视觉分层

三者在策划案里职能不同（卡 = 动作，符文 = 规则改写，装备 = 数值 + 基石卡变体），**视觉上必须一眼分辨**。

| 类别 | 形状语言 | 材质 | 主色 | 一句话 |
|---|---|---|---|---|
| **卡牌** | 竖长方形 | 符纸 / 宣纸 | 按流派分色 | "我这回合要做的事" |
| **符文** | **六边形** | 石 / 玉 / 骨的刻印 | 紫 `FN_RUNE` | "规则被改写了" |
| **装备** | 圆角方形 / 异形轮廓 | 金属 / 皮革 / 现代材质 | 金 `FN_GOLD` + 材质本色 | "我身上带的东西" |

> **符文用六边形是有意的**：它呼应战场六边形，暗示"符文改的是这个世界的底层规则"。而且六边形与卡牌的长方形在缩略图下绝不会混淆。

**卡牌内部信息层级**（从上到下，重要性递减）：

```
① 体力消耗（左上角，最大的数字）      ← 最高频读取
② 卡名（宋体，中）
③ 效果数值（等宽粗体，正文里高亮）     ← 第二高频
④ 效果描述（黑体，小）
⑤ 插画（背景，可被文字压住）           ← 最低优先级
⑥ 标签（底部小字，仅检索用）
```

> **⑤ 插画优先级最低，这一点要写进外包需求。** 卡牌插画很容易画得又满又漂亮，然后玩家读不清数字。策划案 §7.5 要求卡牌数值系数化（伤害随 ATK 成长），意味着**卡面数值是动态的、会变成三位数** —— 插画必须给数字留出足够的低对比区域。

## 13. 美术红线（明确不做什么）

| 红线 | 理由 |
|---|---|
| ❌ **不做血浆、内脏、断肢、尸体特写** | 本项目的恐怖来自**逻辑错误**（§2）。血浆会把它拉低成廉价恐怖，且提高分级与平台风险。所有 AI prompt 必带 `no gore` |
| ❌ **不做突然出现的 jump scare** | 45 分钟一局、要玩几百小时。jump scare 第二次就失效，第十次变成骚扰 |
| ❌ **不做无源的紫色氛围光** | §5.1。廉价感第一来源 |
| ❌ **战斗中不做镜头旋转 / 抖屏遮挡** | 六边形战场旋转后玩家失去方位感；抖屏影响精确点击 |
| ❌ **场景里不出现高明度亮红** | §10.1。会摧毁"红 = 威胁"的信息通道。场景红的明度上限 45% |
| ❌ **不把功能色用于装饰** | §4.4。功能色是玩家的信息通道 |
| ❌ **不做古风 / 仙侠画风** | "东方"在本项目里是**符号与母题**，不是画风。画风底子是**现代写实城市** |
| ❌ **不做过量东方符号堆砌**（满屏灯笼、遍地牌坊） | §2 用量规则：每房间 ≤3 条。堆砌 = 主题变装饰 |
| ❌ **不为腐蚀度重绘场景** | §11。必须走后处理 + 贴花 |
| ❌ **不做超过 0.4s 的战斗特效** | R8 |
| ⚠️ **不使用来源不明的参考图作为最终资产** | moodboard 阶段的 AI 生成图与网络参考仅供内部沟通；正式资产必须原创或有明确授权 |
